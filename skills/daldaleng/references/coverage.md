- 달달영어 5개 프로젝트 목록 1,170건 전체 페이지 조회 및 본문/댓글 수집 완료.
- 연계 플랫폼 목록 760건에서 제목/직접 연결로 선정한 65건 추가 조회.
- 총 1,235건, 로그 5,564개(본문 있는 댓글 5,560개), 본문/로그 약 455만 문자. 반환 totalCount와 수집 로그 개수 일치, 조회 실패 0건.
- 알려진 외부 참조 16건 중 14건은 플랫폼 프로젝트에서 찾아 읽음. 두 참조 4265582448641466618, 4414009318663595089는 접근 가능한 프로젝트 목록에서 projectId를 식별하지 못해 원문 미확인. HTTP 오류로 확인한 것은 아님.
- 운영 가이드 wiki는 Home 하위가 없었다. 구축 wiki의 개발/백엔드 계층은 일부 탐색했다. 전체 wiki 분석을 완료한 것은 아니다.
- 첨부 이미지/PDF/문서 및 외부 Figma/Google 문서 원본은 이번 일괄 조사에서 다운로드·분석하지 않았다. 이전 요청의 완강 AS-IS PDF는 별도로 읽은 근거다.
- 메타데이터/본문 수집·키워드 검색과 선별 티켓 의미 분석은 다른 단계다. 주요 운영/정책 티켓의 본문·최신 댓글은 references에 해석과 날짜를 남겼다. 나머지는 인덱스로 찾아 실제 작업 시 원문을 다시 읽는다.
- MCP에는 티켓 식별자·주제·기술 키워드·조회 범위와 선별 분석을 저장한다. 계정/학생 개인정보가 섞인 전체 원문을 로컬 skill에 복제하지 않는다.

## 심층 추적한 흐름

회원/인증→학생 시간표, BO 공통 편성→학생 누락 상세, 학습/쌍둥이→페이지/답안, 전체 완강, 리포트 기간/저장→배치 호출→화면, 주·월 랭킹, LMS null/status 계약, 질문 첨부/답변, Quartz 조건/수동 실행/재처리, 콘텐츠 평균과 DB 이벤트 이력.
전체 Git 이력은 SHA/날짜/제목/변경 경로/HEAD 도달 여부를 인덱싱했고, 관련 핵심 diff를 선별 검토했다. 3,899개 diff 전체 리뷰를 주장하지 않는다.

- 완강 SQL 19개 synthetic 학생 fixture 및 실제 getMmbrScheduleInfo mapper와 모델링한 Java 조건 비교 통과. 날짜/주차 경계 포함.
- 독립 에이전트가 질문 첨부, 공통 시간표 반영, 월간 수동 실행, LMS null 변경 시나리오를 소스와 비교했다. 발견된 경로·조건·부작용을 수정하고 재검토 통과.
- skill frontmatter 검증과 33개 파일의 UTF-8/참조 링크/Python 문법/YAML/인증키·JWT literal 검사를 통과했다. 나머지 두 SELECT 예제도 같은 fixture DB에서 대상 회원 범위와 집계값을 확인했다.
